Launch a subagent in the background, isolated in its own git worktree, and return immediately.

Use when you need to hand off an independent piece of work (implementation, exploration, tests) that can run while you continue talking to the user. The subagent edits files inside its own worktree checkout, so it can never conflict with your own changes.

Usage notes:
1. You will be notified automatically when it finishes. The injected result includes the worktree branch — merge it into your current branch (git merge <branch>), resolve conflicts if any, then clean up with worktree_delete.
2. Do not duplicate the delegated work or touch the same files while it runs. Continue with non-overlapping tasks or briefly tell the user what you launched.
3. Set worktree: false to run in the current directory instead (like a background task) when the work does not need isolation.
4. Each delegation starts a fresh subagent session. Pass the task_id from a prior result to continue the same subagent session.
