Launch a subagent in the background and return immediately.

Use when you need to hand off an independent piece of work (implementation, exploration, tests) that can run while you continue talking to the user. The subagent runs inside the current session's directory (and therefore its worktree), so its edits land on your session's branch.

Usage notes:
1. You will be notified automatically when it finishes. The injected result includes the session's worktree branch — merge it into your current branch (git merge <branch>), resolve conflicts if any, then clean up with worktree_delete.
2. Do not duplicate the delegated work or touch the same files while it runs. Continue with non-overlapping tasks or briefly tell the user what you launched.
3. Set worktree: true to run the task in a fresh git worktree instead, when the work needs stronger isolation from the current session's own edits.
4. Each delegation starts a fresh subagent session. Pass the task_id from a prior result to continue the same subagent session.
